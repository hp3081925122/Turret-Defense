# 首期配方推导与冲突裁决

用户确认：T1 用普通合成台；高级机器等级通过界面精确扣材料升级，JEI 展示升级配方。升级沿用已有机器，不把旧机器当成额外扣款。

用户确认：高爆榴弹、高压电弧弹一次产出均为 8 发。

用户确认：普通塔头损毁保留底座共享插件；核心殉爆时每个底座统一结算一次插件掉落。

核心高级升级遵循最终文档引用的旧 §2.4 合成材料总量（4/8/16/32 红石块；没有改为旧 §2.5 的另一份红石粉数量），并累计支付 10,000/30,000/80,000/200,000 FE。塔头支付 2,000/5,000/12,000/25,000 FE。底座只扣材料，文档没有规定额外 FE。

升级材料先从玩家背包原子预留，保存进机器 NBT。取消退还预留材料为掉落物，已经支付的 FE 不退。机器损毁时退还未完成升级材料。

专属材料：脉冲=炮塔核心，粒子=石英，榴弹=火药，激光=紫水晶，电弧=铜锭。每个核心管理上限默认32底座，所以200塔头压测需要把配置至少改为34，不能用默认配置假装200塔头已绑定。
