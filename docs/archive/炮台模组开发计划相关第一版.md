## 1. 项目概述

### 1.1 模组定位

一个以 **基地核心** 为枢纽的科技风格防御模组。玩家建造基地核心，围绕核心部署炮塔，通过能量网络和物资供应维持防御体系运转。

### 1.2 核心设计原则

| 原则 | 说明 |
|:---|:---|
| **基地核心是唯一枢纽** | 能量、修复、护盾、终极防御、物资补给全部由核心统一管理 |
| **炮塔只负责攻击** | 所有辅助功能（修复、护盾、对空强化）由核心提供 |
| **特殊效果插件化** | 减速、眩晕、连锁、穿透、爆炸等全部通过插件实现 |
| **每种炮塔后期都有用** | 独特基础机制保证不可替代性，不做淘汰设计 |
| **全地形自适应内建** | 无需插件即可适应地面、空中平台、海平面基地 |
| **前期纯能量，后期需物资** | T1-T3 无弹药，T4-T5 需弹药但属性大幅提升 |
| **全体陆空兼备** | 所有攻击型炮塔均可攻击空中和地面目标 |
| **AE2 深度联动** | 核心可接入 ME 网络，自动补给弹药和能量 |
| **战利品自动回收** | 炮塔击杀掉落物自动传回基地，经验压缩为附魔之瓶 |

## 2. 基地核心

### 2.1 核心方块

- **类型**：单方块（非多方块结构，降低实现难度）
- **防水防爆**：免疫爆炸和水
- **可放置地形**：地面、空中平台、海平面、水下

### 2.2 核心功能清单

| 功能 | 说明 |
|:---|:---|
| **能量生产** | 内置燃烧发电机，烧可燃物产生 FE |
| **能量存储** | 默认 10,000 FE，可扩展 |
| **能量分配** | 自动向范围内炮塔供能 |
| **自动修复** | 持续修复范围内所有炮塔 |
| **护盾投射** | 为范围内炮塔提供额外护盾层数 |
| **对空强化** | 可安装防空模块，为炮塔提供对空伤害加成 |
| **基地级偏转护盾** | 偏转范围内敌方弹射物 |
| **终极防御** | 终焉裁决，条件激活，全图打击 |
| **炮塔管理** | GUI 显示所有炮塔状态 |
| **权限控制** | 信任玩家列表 |
| **AE2 联动** | 接入 ME 网络，自动补给弹药和能量 |
| **战利品回收** | 接收炮塔传回的掉落物与附魔之瓶 |

### 2.6 核心状态

### 2.8 殉爆机制

| 项目 | 说明 |
|:---|:---|
| **触发条件** | 核心方块被破坏（非能量耗尽） |
| **范围** | 半径 64 格内所有炮塔 |
| **连锁** | 每座炮塔间隔 0.5 秒依次爆炸 |
| **插件** | 基础 50% 掉落 / 高级 30% / 特殊 10% |
| **弹药** | 爆炸弹引爆，普通弹 50% 掉落 |
| **能量** | 全部释放，周围炮塔波动 |
| **底座** | 保留（防爆），变为空底座 |
| **恢复** | 重新合成核心，空底座自动重建 |

## 4. 炮塔系统

### 4.1 炮塔结构

- **底座（Base）**：5 个等级，决定插件槽数量、生命值、护盾层数
- **炮塔头（Turret Head）**：决定攻击方式，可拆卸替换
- **插件槽（Module Slots）**：安装功能模块

### 4.2 底座属性

| 等级 | 生命值 | 护盾层数 | 插件槽 |
|:---|:---|:---|:---|
| T1 | 20 | 10 | 1 |
| T2 | 30 | 15 | 2 |
| T3 | 40 | 20 | 3 |
| T4 | 55 | 28 | 4 |
| T5 | 70 | 36 | 5 |

- **底座防爆**：免疫所有爆炸伤害
- **底座防水**：不会被水破坏
- **底座不可被普通攻击摧毁**：伤害由炮塔头承受

### 4.3 炮塔自动修复循环

```

正常运作 → 受损（核心自动修复）→ 被摧毁（仅能量不足时）→ 重建中 → 正常运作
```

- **受损**：核心健康时，炮塔生命值最低降至 1 点，不会归零
- **被摧毁**：仅当核心能量不足、修复停止时，炮塔生命值归零消失
- **重建**：底座保留，核心消耗 200 FE/秒重建，30 秒完成
- **插件/弹药**：被摧毁时 100% 保留在底座数据中，重建时恢复

## 8. 战利品与经验自动收集传输

### 8.1 设计目标

- 炮塔击杀生物后，掉落物**不生成实体**，直接进入炮塔内置缓存。
- 经验值**直接压缩为附魔之瓶**，进入缓存。
- 无需任何升级即可实现。
- 缓存满后，自动将产物转移到基地核心附近。
- 避免大量掉落物实体导致卡顿。

### 8.2 炮塔内置缓存

| 属性 | 说明 |
|:---|:---|
| **容量** | 默认 27 格（相当于一个箱子） |
| **升级** | 无需升级，所有炮塔默认拥有 |
| **物品拾取** | 炮塔击杀的生物，掉落物直接进入缓存，不生成实体 |
| **经验处理** | 击杀获得的经验直接转换为附魔之瓶，存入缓存 |
| **经验压缩比例** | 每 7 点经验压缩为 1 个附魔之瓶（不足 7 点累积） |
| **缓存满时** | 停止拾取新掉落物，并尝试传输到基地核心附近 |

### 8.3 传输机制

| 机制 | 说明 |
|:---|:---|
| **传输频率** | 每 5 秒检查一次缓存 |
| **传输目标** | 基地核心附近的“输出缓存区” |
| **输出缓存区** | 核心周围 5×5×5 范围内的容器（箱子、ME 接口等） |
| **传输方式** | 优先通过 AE2 ME 网络传输；无 AE2 时通过核心内置无线传输 |
| **传输优先级** | 先传输附魔之瓶，再传输普通掉落物 |
| **核心缓存满时** | 物品在核心附近生成掉落物实体（最后手段） |
| **无核心时** | 炮塔缓存满后停止拾取，发出警告提示玩家 |

### 8.4 防卡顿措施

| 措施 | 说明 |
|:---|:---|
| **不掉落实体** | 击杀后直接入缓存，避免大量物品实体 |
| **经验压缩** | 经验转为附魔之瓶，减少实体数量 |
| **批量传输** | 每 5 秒批量传输，避免高频操作 |
| **缓存上限** | 缓存满后停止拾取，防止无限堆积 |
| **核心输出缓存** | 核心附近容器满后，最后才生成掉落物 |

## 9. AE2 联动

### 9.1 物资自动补给

| 方案 | 说明 |
|:---|:---|
| **ME 接口 + 存储总线** | 核心附加 ME 接口，标记弹药并设置维持数量，自动从 ME 网络抽取 |
| **P2P 通道-物品** | 向多个炮塔快速配送物资，物品均分到各输出端 |
| **ME 样板供应器** | 配合 P2P 通道，实现弹药自动合成与分发 |
| **过载 ME 接口（附属）** | 支持无线模式，向远程机器持续供应配置物品 |

### 9.2 能源网络联动

| 方案 | 说明 |
|:---|:---|
| **能源接口** | 将 ME 网络存储的 AE 能量以 FE 形式输出，提取速率 ≤ 网络总容量 30%，上限 500MFE |
| **Flux Applied（附属）** | 添加 FE 存储元件，核心通过能源端口直接访问 |
| **P2P 通道-FE** | 无线能量传输，按各目标需求比例分配 |

### 9.3 战利品回收联动

- 炮塔缓存中的掉落物和附魔之瓶，优先通过 ME 网络传输到 ME 存储。
- 若 ME 网络不可用，则传输到核心附近容器。
- 核心可设置“战利品输出 ME 接口”，自动将产物送入 ME 网络。

### 9.4 配置项

| 配置项 | 说明 |
|:---|:---|
| `enableAE2Integration` | 总开关 |
| `autoRefillThreshold` | 弹药自动补充阈值（默认 20%） |
| `energyConversionRate` | FE 与 AE 转换比例（默认 2 FE = 1 AE） |
| `wirelessRange` | 无线传输最大有效范围 |

```
基地核心（唯一枢纽）
├── 能量生产（燃烧发电 + FE 接口 + AE2 能源接口）
├── 能量存储与分配
├── 自动修复光环
├── 护盾投射
├── 对空强化模块
├── 基地级偏转护盾
├── 终焉裁决（终极防御）
├── 炮塔管理 GUI
├── AE2 物资补给（ME 接口 + P2P 通道）
├── 战利品回收（附魔之瓶 + 掉落物）
└── 殉爆机制

炮塔（15 种，只负责攻击）
├── 底座（5 级，防爆防水，插件槽）
├── 炮塔头（可替换）
├── 插件槽（攻击/防御/功能/特殊）
└── 内置战利品缓存（27 格，经验压缩为附魔之瓶）

插件系统
├── 攻击类（伤害/射速/射程/穿透/爆炸/元素）
├── 防御类（护盾/装甲/反伤/维修）
├── 功能类（目标优先/友军识别/节约/伪装/雷达）
└── 特殊类（自爆/复仇/模式切换/过载/集束/回旋/蓄能等）
```

### 12.2 玩家体验循环

1. **前期**：建造核心 → 烧煤发电 → 建造 T1-T2 炮塔 → 战利品自动回收
2. **中期**：升级核心 → 解锁修复/护盾 → 升级 T3 炮塔 → 安装插件
3. **后期**：升级 T4-T5 → 建立弹药生产线 → AE2 自动补给 → 全塔种混合布局
4. **终局**：终焉裁决作为终极防线 → 保护核心 → 维持能量

### 12.3 核心设计原则

1. **基地核心是唯一枢纽**，炮塔只负责攻击
2. **每种炮塔后期都有用**，独特机制保证不可替代
3. **全地形自适应内建**，无需插件即可适应各种基地
4. **前期纯能量，后期需物资**，平滑过渡
5. **插件系统提供深度**，自由组合定制
6. **AE2 深度联动**，自动化物流与能源管理
7. **战利品自动回收**，经验压缩为附魔之瓶，防卡顿
8. **全部可配置**，方便整合包作者调整
