## 冻结接口

- 核心原库存0–45不变，新增模块槽46–50；底座0–31与玩家预设不变。旧核心库存NBT升级到51槽时保留所有原物品。
- 新增 `core.coreModules: List<CoreModule>`，`core.stats` 返回基础表经过核心模块修正后的缓存。战利品永远只进入19–45。
- 新增 `head.renderTarget: Vec3?` 和 `head.dynamicRender: Boolean` 客户端状态；动态模型数据由独立客户端辅助类提供。
- 动画同步使用 `AimUpdates.queue(head, target: Vec3?)`、`flush(level)`、`register(channel)`；包号4，动画只给附近玩家，不占AUI状态轮询。
- GUI请求增加 `open_help`、`open_details`（face0–5）、`back`、`switch_mode`、`target_policy`、`target_lists`，沿用权限/距离/菜单/限频检查。
- GUI状态增加 `page`、`detailFace`；塔头信息增加stats（damage/range/energy/cooldown/aoe/chain/pierce）、ammo、mode、modules。旧字段保留。
- 帮助页和详情页使用 `TurretDefense.showHelp()`、`showDetails(face)`、`backToMachine()` 和现有 `getStateJson/text`；语言键由资源整合阶段合并。
- 新炮塔ID固定为gravity/railgun/phase/sniper/arbiter/fusion/acid/cryo/emp/graviton，已有五种ID不改。
- 可选AE2不写mods.toml；无AE2仍能启动及执行全部基础功能。自动化优先ME，再普通容器，余额留核心库存。

## 风险与处理

| 风险 | 处理 |
|---|---|
| 新模块破坏原46槽存档或战利品塞入模块槽 | 固定原索引、补NBT兼容与全槽服务端测试 |
| 反射弹射物重复偏转或友军误拦 | 同实体改速、入射方向检测、冷却标记、所有者/信任过滤 |
| BER近远切换重复炮管或远处消失 | 近处动态、远处完整静态模型；模型数据变更才请求重烘焙，验证无重叠 |
| 新控制/护甲状态永久修改生物属性 | 使用可到期效果与独立属性修饰，卸载/重启后由效果生命周期恢复 |
| 37类插件互相递归触发 | 次级伤害不再次调用主命中钩子，限制候选数量与连锁深度 |
| AE2重复扣物品或网络未连接 | 先模拟再精确提交，以返回实际数量为准；断网回退原库存 |
| 外部容器和废弃基地增加负载 | 定时已加载位置扫描，原生结构分布，无强加载 |

## 未定数值的原则

不改变已冻结数值。新增护盾偏转耗能按等级50/75/100/150/200FE，能量降低时拦截率按可配置倍率下降；外部容器采用5×5×5（半径2），另设可配置半径，避免把边长5误作半径5。其他缺失数值逐模块写入扩展配置与开发记录；后续测试据真实结果调整，不以缩减效果实现代替。

## 验收

每阶段至少编译；完整整合后服务端GameTest覆盖旧功能、新模块/控制、库存兼容、软依赖回退、结构数据解析。客户端显示与实际AE2网络互操作没有实测时保持待验证。性能沿用用户“实用即可”要求，保留数据。

## 2026-10-15通用仇恨补充

用户明确禁止用任何具体物种单独兼容来宣称功能正常。扫描、快照、瞄准及命中统一使用Mob；敌对分类使用Enemy，当前中立仇恨使用NeutralMob接口，归属保护使用TamableAnimal和队伍关系。移除了史莱姆专用类型分支与移动控制器反射；生物反击使用同一个Mob Goal、导航和有上限的碰撞移动补偿。测试可以使用具体物种作样本。

每个塔头独立保存敌对、仅还击、白名单、所有非友方生物四种策略，以及各最多32项的白名单、黑名单。黑名单优先，保护友方宠物与队友；设置无需优先级插件。网络载荷上限16384字符，注册ID每项最多128字符。未知ID拒绝整次名单更新，避免误清空已有设置。

新增缺失值默认配置：聚变高级弹药每20tick消耗一次；电弧水下跳跃范围×1.5；通用导航失败时的水平加速度上限0.045，水平速度已有上限，不强制传送或穿透方块。原有完整伤害类型已进入bypasses_cooldown标签，持续束每2tick结算不会被原版无敌帧吞掉。

后续配方作为可由数据包覆盖的初始材料方案，已区分各塔种、弹药、插件和核心模块，不能将多个产物放在相同输入配方上。原首期配方及冻结产量保留。
